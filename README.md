# 文献阅读（law-mgmt-paper-reader）

这是一个把「文献阅读」技能打包为 DeepSeek Harness 插件的 bundle。

技能面向人文社科，重点是法学与管理学的论文精读、批判性阅读和文献综述。安装并启用本插件后，`law-mgmt-paper-reader` 会出现在技能目录中；在对话里提出读论文、解释某篇文章、拆解论证、比较文献、梳理研究现状、找研究空白，或阅读专著章节、判决与规范文本时，模型会加载该技能并按其规则展开。

技能正文内嵌在本包中，无需额外参考文件。关闭或移除本插件后，该技能即从技能目录中消失。

# Paper reading skill (law-mgmt-paper-reader)

A DeepSeek Harness bundle that ships the "文献阅读" skill as a plugin.

The skill assists close reading, critical review, and literature synthesis for humanities and social sciences, with a focus on law and management papers. Once installed and enabled, `law-mgmt-paper-reader` appears in the skill catalog; the model loads it when you ask to read a paper, explain an article, break down an argument, compare sources, map the research landscape, or read monograph chapters, judgments, and normative texts.

The skill body is embedded in this package and needs no external reference files. Disabling or removing this plugin removes the skill from the catalog.
